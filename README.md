# ITnLM
Material for the class: *Information-Theoretic Analysis of Language Models*


## Class years
- Spring 2024/5
- Spring 2023/4
- Fall 2022/3

## Description
This class is in a workshop/seminar style. Students taking on a projects at the intersection of inforamtion theory and language modeling. The project is presented in class using a coding notebook and submitted after instructor comments for archiving. This repository contains current and past final presentation notebooks. 


- presentations: final class presentation of students
- notebooks: jupyter notebooks covering relevant material
- data: datasets used in class and/or in home assignments
- reading: additioanl reading material
